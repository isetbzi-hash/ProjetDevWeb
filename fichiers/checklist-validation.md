# Checklist de validation — Bizerte Voyages

À cocher après les tests sur l'adresse publique GitHub Pages.

- [ ] La page publique s'ouvre correctement en HTTPS.
- [ ] Le menu horizontal fonctionne sur ordinateur.
- [ ] Le menu burger s'ouvre et se ferme sur téléphone.
- [ ] Les liens Accueil, Nos circuits, Galerie et Demande de devis mènent aux bonnes sections.
- [ ] Les trois images des circuits s'affichent.
- [ ] Les trois cartes ont la même hauteur.
- [ ] Les six photos de la galerie s'affichent.
- [ ] Le formulaire affiche correctement ses libellés et ses champs.
- [ ] Le bouton d'envoi est visible et utilisable.
- [ ] L'alerte de succès peut être fermée.
- [ ] Aucun défilement horizontal n'apparaît à 375 px.
- [ ] Aucun défilement horizontal n'apparaît à 1440 px.
- [ ] Aucune erreur rouge n'apparaît dans l'onglet Console.
- [ ] Aucune ressource du projet ne retourne une erreur 404 dans Network.
- [ ] Le poids total des images et ressources de la page est inférieur à 2 Mo, conformément à l'objectif de l'atelier.
- [ ] Les changements validés ont été commités et poussés sur la branche `main`.
